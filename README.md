# Roleplay Story - The Gothic Library

iPhone向けのPWAプロトタイプです。

## 現在使える機能
- 作品の作成・編集・削除
- 作品ごとの世界観・メモ管理
- キャラクター作成、プロフィール、画像保存
- Chapter / Episodeの作成・編集・削除
- 作品ごとの執筆ログ保存
- 会話ログのテキスト書き出し
- 全データのJSONバックアップ・復元
- PWAのオフラインキャッシュ

## 重要な制限
この初版は「作品管理・執筆ノート」です。AIの自動返信機能はまだ接続していません。
完全無料でAIを使うには、iPhone上で動く小型ローカルモデルとの接続検証が別途必要です。iPhone 14での速度・対応可否はモデルとブラウザ環境に依存し、保証できません。

## iPhoneで使う方法
PWAとしてホーム画面に追加するには、HTTPSで公開されたWebサイトとして配置する必要があります。
1. ZIPを解凍し、ファイル一式をHTTPS対応の静的ホスティングにアップロードします。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」を選びます。
4. ホーム画面のアイコンから起動します。

ローカルデータはSafariのWebサイトデータ内に保存されます。SafariのWebサイトデータ消去で失われる可能性があるため、設定画面から定期的にJSONバックアップしてください。
